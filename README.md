# Empório da Música: customer service agent

Prototype of a text-message customer service agent for Empório da Música, a (fictional) musical instrument store in Campo Grande/MS.

Work in progress. Full documentation will be added as the project evolves.

## Data

`data/` holds the material provided by the store. File names were simplified
(`desafio_tecnico_ai_eng - products.csv` became `products.csv`, and
`políticas_da_loja.pdf` became `politicas_da_loja.pdf`, without the accent) to avoid
spaces and non-ASCII characters in paths.
